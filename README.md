# ☕ Cafetería Origen - Sistema Punto de Venta (POS)

Un sistema de punto de venta web moderno y liviano diseñado para la gestión de ventas, control de menú e integración con bases de datos relacionales en tiempo real.

---

## 🚀 Tecnologías Utilizadas

### **Backend**
* **Node.js** & **Express**: Servidor HTTP y API RESTful.
* **PostgreSQL**: Base de datos relacional para el menú, usuarios y registros de ventas.
* **`pg` (node-postgres)**: Cliente para la conexión y consultas SQL a PostgreSQL.
* **dotenv**: Manejo de variables de entorno de forma segura.

### **Frontend**
* **React 18** (vía CDN): Renderizado dinámico de la interfaz y manejo de estado.
* **HTML5 / CSS3**: Diseño responsivo basado en CSS Grid y Flexbox.
* **Babel**: Transpilación de sintaxis JSX directamente en el navegador.

---

## 🛠️ Requisitos Previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

* [Node.js](https://nodejs.org/) (versión 16 o superior)
* [PostgreSQL](https://www.postgresql.org/) instalado y en ejecución.

---

## 📦 Instalación y Configuración

### 1. Clonar el repositorio

git clone [https://github.com/tu-usuario/cafeteria-origen-pos.git](https://github.com/tu-usuario/cafeteria-origen-pos.git)
cd cafeteria-origen-pos

### 2. Instalar dependencias del Backend

Dentro de la carpeta Backend terminal escribir el siguiente comando:
- npm install

## 🏃‍♂️ Ejecución de la Aplicación

### 1. Inicia el servidor Node.js:
- node backend/server.js

### 2. Abre tu navegador e ingresa a:
- http://localhost:3000
